## High-level view

The flip fix is real and lands on the shipped path. `spot_shifted_gamma_source` / `solve_gamma_flip_bs` recompute `gamma(S)=phi(d1)/(S·sigma·sqrt(T))` per contract across the scan grid, so the OI-weighted dealer-signed net inventory crosses zero. Both `_build_flip` (live) and `build_kaggle_levels` were switched off the constant-feed source onto the vectorized BS solver, and the committed `230612Z_QQQ.json` now carries a non-neutral flip at 29,634.67 with the Put Wall (negative GEX) below and Call Wall (positive) above it — a genuine sign change, not a degenerate touch-zero.

Strength is now honest and informative. The share denominator moved from two-sided gross to same-side gross (`side_gross_gex`), so a call wall is judged against total call-side gamma. On the real snapshot both Total walls read MODERATE; the field stays flagged `uncalibrated` because Phase-2 re-expresses the bands as quantiles against history that doesn't exist yet. That honesty is preserved.

The 0DTE gap is closed with a committed synthetic snapshot whose quote day is a listed expiry, and two end-to-end tests assert all four walls populate at real MNQ prices, `gex_no_contracts` is absent, strength is non-WEAK, the flip is non-neutral, and both regime signs are definite. These assertions would fail if any of the three fixes were reverted.

The basis outlier bound is wired end to end: `build_levels` passes the raw basis into `corrected_basis`, which flags `BASIS_OUTLIER` when corrected and raw disagree beyond 25 points, and a theoretical cost-of-carry forward is provided as the SS9.1 fallback. The fixture trips the flag at 36.86 points, so a contaminated QQQ→NDX anchor is surfaced rather than silently mapped.

Scope holds. The fix touched no renderer or spec files beyond test expectations; the emitted file is still exactly the four walls + flip + regime with ingredients hidden, the ≤5-line render and skip rules are intact, no-look-ahead still raises on a future asof, and the proxy flag still rides through.

### Spot-repriced flip renders on the shipped path (confirmed)

`spot_shifted_gamma_source` recomputes BS gamma at the hypothetical spot from each contract's IV and exact time-to-settlement, and `solve_gamma_flip_bs` vectorizes the same math over the whole grid so the ~8000-contract live universe evaluates as array ops instead of millions of scalar `scipy` calls. `_build_flip` and `build_kaggle_levels` both now call `solve_gamma_flip_bs` with `time_to_expiry=lambda c: time_to_expiry(c.expiry, c.root, asof_dt)`, so the constant-feed-gamma path that produced permanent `flip_no_root` is gone from production.

The committed `230612Z_QQQ.json` proves the effect: `gamma_flip.mnq_price = 29634.6692`, `neutral: false`. That the root is a genuine sign change and not a degenerate touch-zero is corroborated by the surrounding walls — the Put Wall sits at 28,807.8 with negative GEX and the Call Wall at 30,043.1 with positive GEX, so `NetGEX` transitions negative→positive across 29,634.67. The refactor split the root-finding into `_roots_from_net_curve` (genuine sign changes only, flat-zero regions excluded, shared-node de-dup) and `_assemble_flip` (nearest root, actual sign read off the curve), and both flip solvers share them, so the "read the sign, don't assume it" property carries over.

Revert-sensitivity is real: `test_feed_gamma_source_ignores_spot_but_spot_shifted_does_not` asserts the feed source returns the same gamma at 550 and 600 while the spot-shifted source peaks at the strike, and `test_solve_gamma_flip_bs_finds_root_on_put_below_call_above` asserts a located root strictly between the put and call strikes with `sign_below != sign_above`. Restoring the constant-feed path fails both.

### Side-specific strength is informative and stays honest (confirmed)

`side_gross_gex(profile, side)` sums `|call_gex|` or `|put_gex|` across strikes, and `assess_strength` divides the wall's `abs_gex` by its own side's gross. Because the wall selector already ranks by side-specific `|GEX|`, numerator and denominator are now the same quantity — a true within-side concentration ratio — instead of understating every share ~2× against the two-sided universe. On the real snapshot both Total walls render MODERATE (put wall 11.5%, call wall 7.3% per the commit message; the emitted file confirms MODERATE/MODERATE). The `STRENGTH_UNCALIBRATED` flag and the resolution-floor confidence downgrade are untouched, so the readout is more informative without over-claiming calibration. `test_strength_uses_side_specific_denominator` pins the larger side-specific share and asserts `assess_strength` uses it.

### 0DTE fixture with revert-sensitive end-to-end assertions (confirmed)

`scripts/make_0dte_fixture.py` produces a committed synthetic snapshot at `data/snapshots/2026-09-08/120000Z/` (meta flagged `synthetic_fixture`) whose quote day is a listed 0DTE expiry, and `data/levels/2026-09-08/160005Z_QQQ.json` renders all four walls plus a non-neutral flip at 24,236.95. Two tests drive `build_levels` on it: `test_build_levels_0dte_fixture_populates_all_four_walls` asserts both 0DTE walls land at real MNQ prices and `gex_no_contracts` is absent; `test_build_levels_0dte_fixture_has_informative_strength_and_flip` asserts a non-WEAK 0DTE strength band, `flip.neutral is False` with a real price, and definite (`+`/`-`) regime signs on both universes. Reverting the flip fix breaks the flip assertion; reverting the strength fix breaks the non-WEAK assertion; an empty 0DTE universe breaks the wall-population assertion. The synthetic nature is disclosed rather than passed off as a live capture.

### Basis outlier bound wired end to end (confirmed)

`build_levels` now computes `raw` before `corrected` and threads `raw_basis=raw.basis` into `corrected_basis`, which appends `BASIS_OUTLIER:<delta>` when `abs(corrected - raw)` exceeds 25 points. The committed `230612Z_QQQ.json` carries `basis_corrected_vs_raw_disagreement_exceeds_max:36.8608` in its quality flags, so the sign-flipping QQQ→NDX swing (−15.77 corrected vs +21.10 raw) that v1 flagged is now surfaced on every mapped wall instead of propagating silently. `theoretical_forward(S, tau, r, q) = S·exp[(r−q)τ]` supplies the SS9.1 fallback anchor. Both the flag-trips and no-false-positive cases are tested, along with the fallback. The 25-point threshold is documented against the NQ tick/dollar scale and sits above a clean-fit gap but below the fixture's contaminated swing.

### Stale-bytecode guard and scope

`conftest._purge_stale_bytecode` deletes any `src/gammamap` `.pyc` whose source is newer before collection, closing the v1 trap where a stale compiled `0.02` masked the correct `0.01` GEX factor. It touches only gitignored files and cannot break the run. The fix commit changed no renderer or spec source — only `test_indicator_contract.py` expectations moved (2→3 lines on the weekend fixture now that the flip renders, WEAK→MODERATE strength, plus the flip label), which is a faithful reflection of the fixes, not scope creep. Ingredient-hiding, the ≤5-line cap, skip rules, no-look-ahead, and the proxy suffix all remain asserted and green.

### Kaggle proxy artifact staleness (likely)

`data/levels/kaggle/*.json` were last written in `337bdb0`, before the fix, and still show `neutral: true` flips and all-WEAK strength across every file. The code that generates them (`build_kaggle_levels`) was updated to use `solve_gamma_flip_bs`, and Kaggle CSVs carry `C_IV`/`P_IV`, so regenerating would yield spot-repriced flips and side-specific strength — the committed artifacts therefore no longer match the code. They stay correctly tagged `proxy: true` / `oi_absent_volume_proxy` and never feed the live MNQ path, and regenerating requires the gitignored 628MB raw dataset, so deferring is defensible. The residual risk is purely that a reader treats these diagnostic files as current engine output; a staleness marker or README note would remove the ambiguity.
